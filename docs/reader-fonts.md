# Local reader fonts and native preview coordinates

The article body, imported document text, title measurement, speech highlight carets and live preview now resolve live font records from the reader resource store. File identity revisions refresh the guest texture cache. Deleted, missing, corrupt or unsafe font references use the system fallback; native path traversal is rejected. Reading and previewing do not rewrite saved presets.

The shared Android font implementation follows the installed native reader's `readerTypefaceFor` behavior for collection face, weight, italic and variation axes. Its bounded cache uses canonical path, length, modification time and style. The preview retains the previous font resolver during resource handoff and applies the replacement with the next completed preset update.

Native preview uses balanced/simple/high-quality paragraph strategies and Android line spacing; article text retains the Compose line-height profile. Derived font sizes preserve Kotlin Float rounding. Underline and strike-through use the selected font's native rendering. Async title measurement preserves the reader's existing two-line planning algorithm with the selected font's widths.

Android image quads now retain fractional coordinates, which avoids snapping each text texture to a logical integer at 2x density. The new `TEX_QUAD_F32` opcode requires the corresponding runtime and bundle together. Two physical coverage pixels below preview text preserve antialiased descenders outside the native line box without changing row placement. This margin is verified for the profiles below; arbitrary font overhang and every scale are not qualified.
