# 图片缓存与高级设置

2026-09-14 增量：图片下载改为持久缓存，正文图片预取、全屏图片源文件保留以及缓存上限／媒体缓存／同步媒体保活三个高级设置入口已接通。本增量没有完成全部多媒体缓存或整个迁移。

## 行为

图片缓存保存在独立的 `managed-cache` 命名空间，URL 与请求头经 SHA-256 形成文件名，不在清单里记录地址或凭据。相同请求共享下载，两条下载同时执行；最后一个使用者取消后，未完成的请求停止。完整文件通过既有 HTTP 服务原子发布。缓存命中会校验图片并更新时间；损坏文件重新下载。崩溃遗留的本模块下载临时文件可以回收，未知文件不自动删除。

按原生的两个图片加载器区分正文图片与普通图片／全屏预览：正文图片另有 128 MiB 上限，普通图片受设置中的总缓存上限管理。正文预取使用「关闭、前 4 项、全部」，与原生一样选择去重、非本地的 Image 块，不将 Video 块当作此选项的预取对象。退出页面取消尚未完成的预取；已完成的文件留待重开复用。

自动清理遵循原生 ManagedCacheService 的分桶顺序：先清理抖音预载至保留六项，再处理图片、哔哩哔哩预览，最后允许抖音降至保留四项；离线桶不自动淘汰。正在读取的文件另受使用引用保护。全屏图片一直保留源文件，直到退出且分块解码结束。字体、背景、导入文本、笔记和未知文件不属于自动清理范围。

当前生产缓存写入方是图片。视频预载／预览和 RSS 离线媒体的生成器尚未接入这套管线，不能将分桶策略存在理解为这些功能已经迁移完成。系统分享的后续进展见 [分享](system-share.md)。先前将手动清理列为原生缺失功能有误：原生设置页没有此入口；旧占位项的移除进展见 [设置范围核对](settings-parity-audit.md)。

2026-09-25：B 站页面四处封面写入已改为 `bili-preview` 桶。删除内置频道时清理所属桶并取消待完成下载；抖音删除同时清除 Cookie。应用测试覆盖桶隔离、下载取消以及 B 站／抖音持久化频道删除。OWW242 已覆盖安装对应主包，但没有删除主应用的频道，也没有在设备上验证删除后的缓存内容。抖音视频预载生成器和播放预览缓存仍未接入 PodJS；此处的删除逻辑不能视为完整媒体缓存迁移。当前安装包与数据核对见 [实施状态](implementation-status.md)。

高级设置沿用原生容量档位和文字格式，显示已扫描用量，媒体预取显示「0张／4张／全部」。同步媒体保活开关连接既有的设置保存与同步回调。本次没有修改主应用的用户偏好，也没有通过测试启用主应用静音音轨。

SDK 新增有界的目录枚举和文件访问时间更新。枚举仅在应用文件根内工作，目录内出现符号链接或超过一万项时返回错误；缓存管理器再检查返回路径属于指定缓存目录。

## 证据

495 项应用测试、34 项 SDK 服务测试与 TypeScript 检查通过。单元测试覆盖并发共享、取消与重试、持有期间禁止淘汰、重建管理器后的复用、独立正文上限、路径越界、删除失败、损坏文件及遗留临时文件保护。

独立手表包的两项 Android 测试通过：

- 目录枚举、更新时间、路径逃逸、符号链接和一万项上限。
- 本机 HTTP 服务提供真实 PNG，验证共享下载、关闭／四项／全部预取、两条等待下载的取消及临时文件清理。受控离线文件、阅读资源与未知文件保持不变。
- 直接调用已安装原生参考 APK 的淘汰函数，十组上限的结果一致；九个容量文字及三个预取模式的标签、说明、数量一致。淘汰对照使用独立文件和原生私有函数，不声称运行了完整原生后台维护调度。
- 生产 RemoteImage 和 TiledImage 显示实际图片，检查全屏源文件在清理期间仍被保留。关闭并重新创建 Activity 后，没有重复 HTTP 下载；冷、热两次图片区域像素一致。随后损坏测试缓存，重开后只新增一次下载并恢复正确画面。
- 七种高级设置状态及四张图片画面共十一张截图已保留。设置截图使用受控用量与设置状态，未模拟点击、滚轮或键盘；没有完整原生设置页的逐像素对照。

正式包采用既有 WatchRSS 标签、版本 0.1.0-dev 和 versionCode 1 覆盖安装，没有清除主应用数据。安装后的 DEX 和原生库与已通过测试的独立手表包一致。认证、只读查询、Token 记录、阅读预设及七次预览请求回归通过；该回归通过 ADB 中继，不属于局域网验收。

安装前后 30 张业务表与 188 个受保护非数据库文件一致，仅 WorkManager 的强制停止时间戳更新。测试包与中继已清理，原有参考及手机 APK 哈希保持一致，主应用恢复前台。

收据：`artifacts/managed-cache-deployment-receipt.json`；重验脚本：`scripts/verification/collect-managed-cache-receipt.py`。

## 未验证范围

完整阅读页的物理操作、长时间滚动与缓存压力、真实网络故障组合、所有图片格式、大图与 EXIF、完整原生像素一致性仍未完成。本次沿用现有图片下载和解码边界，不代表它们已与原生所有输入范围一致。视频缓存生成器和离线媒体完整流程继续保持未完成状态；系统分享及设置占位项的后续核对见前述文档。
