# 账号状态页迁移

2026-09-24：将「我的 → 账号」从未迁移提示接入只读账号页。依据原生 `AccountStatusActivity` 的发布版分支：未绑定时显示手机端登录指引与下载弹窗；已绑定时显示脱敏手机号、会员套餐和状态、诊断开关，以及 Access Token / Refresh Token 的**状态文字**。原生仅在 DEBUG 显示的云中继状态不进入发布页。

页面通过 `AppServices.readAccountStatus()` 从现有安全存储读取账号，服务层先转成有限的展示对象。令牌、用户 ID、安装 ID、后端地址和密钥都不传给 UI。到期判断保留原生的 `>0 且 <= 当前时间` 边界；空刷新令牌显示「旧版，需重新同步」。错误与未绑定分开显示，避免读失败时误告知用户未绑定。页面重新成为前台时重读状态，迟到读取结果不会覆盖较新的结果。

本批 TypeScript 检查、674 项 Bun 测试和应用构建通过；其中新增状态映射测试覆盖过期边界与敏感字段不外泄。

独立包 `dev.podjs.tests.accountstatus` 在 OWW242 上通过 1 项 Android instrumentation（12.665 秒）。测试通过生产 `AccountStatusScreen` 和状态投影展示三组**夹具数据**：未绑定、会员有效、会员未生效且令牌过期。GPU 位图分别保存为 [未绑定](../artifacts/account-status-unbound-final.png)、[会员有效](../artifacts/account-status-bound-final.png)、[过期状态](../artifacts/account-status-expired-final.png)；页面及状态文字在可见区域内实际渲染。第二、三组内容超出首屏，需要滚动才能看到底部，本轮没有注入触摸或表冠输入。原始第一轮和延长等待后的过期 PNG 字节哈希相同；先前预览工具显示不完整不是已证实的渲染缺陷，延长等待不记作修复。

构建／安装哈希、图片及源码哈希、测试边界见 [设备收据](../artifacts/account-status-device-receipt.json)。独立测试包及其测试 APK 已卸载；主 PodJS 包始终为 `d8f2f4a1ebe321b3dc628f4656f970fb69fc3cafe66412109142f9e31a24b637`。此证据不覆盖主应用「我的 → 账号」实际导航、真实安全存储账号或手机同步，也没有原生逐像素对照或物理输入结果。真实手机账号同步、云同步、令牌刷新和不同会员状态端到端验证仍在迁移范围内；本批不把只读页面视为账号功能完成。
