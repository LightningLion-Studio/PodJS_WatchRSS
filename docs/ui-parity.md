# 页面 1:1 还原验收

用户要求以当前 Android 源码（包含未提交改动）逐页还原。简化导航、重新设计的卡片或仅功能相似的页面不视为完成。

基准设备：OWW242，ADB `e3aca8af`，实测物理画面 466×466，系统 density 320（2 px/dp）。Home 的 Compose 局部 density 也是 2，因此其坐标基准为 233×233 dp。字体缩放、其他页面的局部 density 必须分别核对。

每个页面分别记录以下状态：

- 源码布局、资源、条件分支与文案已提取。
- 相同数据、登录状态、主题、字体缩放和滚动位置的旧版截图已取得。
- PodJS 页面与旧版对比：位置、宽高、间距、圆角、颜色、字形、基线、换行、省略、图片裁剪。
- 点击、长按、滑动、返回、旋钮、加载及错误状态与旧版一致。
- 实机无遮挡显示和操作已验收。

不把“编译通过”“截图非黑”或“源码数值相同”标记为视觉验收通过。`scripts/compare-ui.py` 只比较同尺寸原始截图，输出像素误差，不自动缩放，也不以任意容差宣称还原完成。

当前首页纠正方向：移除新造的底部四项导航和顶部“订阅”标题；恢复原版“我”圆形入口、备忘录、频道列表/空状态、RSS推荐、加号入口、备案信息的顺序与滚动结构。字体改回原版 `watch_sans.ttf`。

当前状态：所有页面的 1:1 验收均尚未完成。当前手表的长时间充电系统提示遮挡前台；应用纹理截图可辅助检查渲染，但不能代替无遮挡操作验收。

本轮实现状态：

- 已移除旧简化首页；首页采用按实际条目高度定位、可视范围挂载的滚动列。
- 首页空数据布局和“我的”菜单已按 Compose 源码布局重建，使用原字体与 Material 图标路径。
- 仍需对照：Compose 字体基线、超长标题省略号、频道排序/置顶位置、播放状态卡片、滑动操作/长按、下拉刷新，以及其余页面。
- 未完成页面入口明确显示尚未迁移，不能作为功能验收通过依据。
