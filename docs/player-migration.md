# 播放页迁移（Android）

基线为原工作区 `BiliPlayerScreen.kt`、`PlayerVolumeOverlay.kt` 和 `DouyinPlayerActivity.kt` 的当前源码；抖音复用同一播放器，备忘录仍暂停。

## 本批实现

- 共享 TSX 全屏控件：画面模式、90° 旋转、时间、橙色只读进度条、播放/暂停、±4 秒快进退及长按加速；单击显隐、双击暂停。原版没有拖动进度条，不新增常驻标题。
- 标准/铺满/圆内缩小，B 站放大后的画面拖动；圆形侧滑返回与原生视频位移同步。
- 表冠使用框架已归一化的方向，正数对应增加；消除播放器二次反号。虚拟音量累加和串行提交避免快速刻度丢失，起播音量上限在 play 前执行。
- B 站本地断点和原端点历史上报；抖音同会话有界播放队列、上/下一条、页尾加载、去重与取消。
- 原生视频在透明 PodJS 控件层下方，圆形黑底遮挡 letterbox 区域；上一页只在进入播放时抓取一张返回背景，替换/停止/关闭时释放。
- Vulkan 使用预乘透明合成；CPU fallback 使用显式 opt-in 透明增量接口，其他宿主的 opaque 默认接口保留。
